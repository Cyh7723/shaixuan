## 单层严格档筛选标准（与双层严格档完全同口径）

对单一材料同时要求：

| 条件 | 阈值 | 说明 |
|---|---|---|
| 对 Li 稳定 | Er(Li, X) ≥ −0.02 eV/atom | 与双层三界面同阈 |
| 对 SSE 稳定 | Er(X, SSE) ≥ −0.02 eV/atom | LZC/LYC 分别判 |
| 离子传输 | E3D ≤ 0.6 eV | BVSE 严格档 |
| 电子绝缘 | Eg ≥ 1.0 eV | 单层必须自身绝缘 |
| 还原窗口 | V_red ≤ 0.1 V | 与双层 A 层同阈 |

## 结果

| 口径 | 通过数 |
|---|---|
| **LZC 单层严格档** | **2 种：LiCl、LiBr** |
| **LYC 单层严格档** | **0 种**（LiCl −0.0227、LiBr −0.0227、LiI −0.0266 全部卡在 −0.02 线下） |
| LZC 近失档（Er 放宽到 −0.05） | +LiF、LiI → 4 种 |
| LYC 近失档（Er 放宽到 −0.05） | 3 种：LiCl、LiBr、LiI |
| 双 SSE 同时过严格档 | **0 种** |

## 解读

1. **单层严格档近乎归零（LZC 仅 2、LYC 为 0、双 SSE 交集为 0），而同口径双层有 196 对通过**——这是双层设计必要性的最直接量化证据：把"对 Li 稳定"与"对 SSE 稳定"两个互斥要求拆给两层后，解空间从 0/2 恢复到近两百对。
2. LYC 归零的直接原因：最优三种材料 Er(LYC) 均落在 −0.022~−0.027 区间，恰好在 −0.02 阈值下方；这不是材料失效，而是阈值位置与 LYC 反应能分布的相对关系所致（LYC 对涂层整体比 LZC 更"活泼"一点：LZC 最优是精确的 0）。放宽到 −0.05 后 LiCl/LiBr/LiI 全部回归，说明结论对该阈值敏感，报告时应同时给出两档。
3. 由此，双层路线的推荐组合（如 LiI|LiCl）中 B 层对 SSE 的兼容性正是单层材料自己做不到的：LiI 单层 Er(LYC)=−0.0266 不过线，但 LiI 贴 Li + LiCl 贴 SSE 的分工组合轻松通过。
